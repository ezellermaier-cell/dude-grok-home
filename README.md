# DUDE — Grok Home Assistant

Android 10+ smart-display assistant starter. Includes tap-to-talk voice input, text-to-speech, local sample commands, xAI Grok chat integration, and a GitHub Actions APK build workflow.

## Build
Open Actions and run **Build Android APK**. Download the `dude-debug-apk` artifact from a successful run.

## Current scope
The initial app provides tap-to-talk and Grok chat. Always-on Hey Dude wake-word detection and Smart Life/Tuya, LG ThinQ, Sensi, and Shark integrations are not yet implemented.

Never commit API keys. Configure your xAI key inside the app.
