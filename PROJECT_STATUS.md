# DUDE project status

## Included
- Android tablet dashboard
- Tap-to-talk voice input using Android speech recognition
- Text-to-speech responses
- xAI chat completions integration using grok-3-mini
- API key settings stored in app-private preferences
- Local sample responses for common phrases
- GitHub Actions debug APK build

## Not yet implemented
- "Hey Dude" always-on wake-word service and custom Porcupine model
- Secure backend proxy for production API key handling
- Smart Life/Tuya, LG ThinQ, Sensi and Shark device integrations
- Device discovery, authorization and control confirmations
- Calendar, weather, news and reminders

The starter app does not pretend those integrations are active.
